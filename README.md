# Travel with Friends 2027

Comparación de 12 propuestas de viaje grupal: costos completados y auditados, checklist, cuestionario individual de afinidad y votación en dos etapas.

Abre la página (GitHub Pages) o el archivo `index.html`. Todo corre en tu navegador: tus respuestas y votos se guardan solo ahí y no se envían a ningún servidor.

- Datos al 12 de noviembre de 2026. Los precios de 2027 no están publicados: todo lo contrastado es de 2026.
- El índice de afinidad no es una probabilidad de satisfacción ni una prueba psicológica validada.
- Esta página no hace reservas ni pagos.
